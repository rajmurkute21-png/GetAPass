# GetApass — The Event Experience, by Design

GetApass provides rapid collegiate booking, verified payments, real-time digital passes, and instant gate QR validation. A complete interface language for organisers, attendees, and entry teams.

## Brand Assets
The official brand identity assets are located in `public/brand/`:
- `logo-light.png` - Light mode logo (Dark text with electric violet ticket badge)
- `logo-dark.png` - Dark mode logo (White text with electric violet ticket badge)
- `favicon.png` - Square ticket icon with brand mark
- `app-icon.png` - App icon squircle variation
- `logo-monochrome.png` - Monochrome high contrast logo

Vector graphics:
- `public/favicon.svg` - Scalable vector favicon
- `src/components/common/Logo.jsx` - React brand logo component with `light`, `dark`, `monochrome`, and `icon` variants.

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
